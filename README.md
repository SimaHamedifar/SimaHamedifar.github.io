# Sima Hamedifar — Personal Portfolio Website

A responsive, single-page portfolio website written in HTML, CSS, and JavaScript.

## Preview locally

Open `index.html` in any web browser. No installation, build tools, or API keys are required. An internet connection loads the optional Google Fonts.

## Publish on GitHub Pages

1. Create a public GitHub repository named `SimaHamedifar.github.io`.
2. Upload `index.html` to the repository root.
3. In the repository's **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Your website should be available at `https://simahamedifar.github.io/` once deployment completes.

## Personalize before publishing

- Replace the LinkedIn *search* link with your exact LinkedIn profile URL.
- Add a professional email address/contact method if desired.
- Add direct links to your other project repositories and peer-reviewed papers.
- Review project descriptions and role titles against your current CV.
- Optionally add a personal portrait and downloadable CV.
